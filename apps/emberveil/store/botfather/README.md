# Эмбервейл — набор для @BotFather

Бот: **@emberveil_game_bot** · Mini App: `https://t.me/emberveil_game_bot/play`
Игра: `https://emberveil-dwp.pages.dev/emberveil/` · API: `https://emberveil-api.emberveil.workers.dev`
Юридические страницы (после деплоя Pages): `https://emberveil-dwp.pages.dev/legal/privacy.html`, `…/legal/terms.html`

Картинки в этой папке отрендерены из самой игры (стенд `apps/emberveil/tools/harness.js`) и оформлены шрифтами игры:

| Файл | Размер | Куда |
|---|---|---|
| `userpic_640x640.png` | 640×640 | /setuserpic — аватар бота (Сердце Брода с угольным кристаллом; Telegram обрежет в круг — всё важное в центре) |
| `description_640x360.png` | 640×360 | /setdescriptionpic — картинка на пустом чате до «Старт» (герой против Пепельного Колосса + название) |
| `miniapp_cover_640x360.png` | 640×360 | /myapps → Edit Photo — обложка Mini App (Сердце Брода в сумерках + название) |

Видео/GIF (по желанию, ≤10 с, 640×360) пока не сделано: можно записать бой с телефона и загрузить в /myapps → Edit GIF.

## Пошагово

Откройте @BotFather, отправляйте команды и выбирайте `@emberveil_game_bot`.

### 1. Описание — `/setdescription` (≤512 символов; видно в пустом чате до «Старт»)

```
Эмбервейл — тёмное фэнтези прямо в Telegram.

Мир Вейла угас, остался последний уголь — и он в твоих руках. Сражайся в динамичной экшен-RPG: уклоняйся, руби, колдуй и валь боссов, от Гнилокорня до Пепельного Колосса. Отстрой сгоревшую деревню, собери отряд, вступи в клан и устраивай набеги.

Каждый выбор меняет историю — 4 разных финала.

Бесплатно, без скачивания. Жми «Играть».
```
(381 символ)

### 2. «О боте» — `/setabouttext` (≤120 символов; в профиле бота)

```
Экшен-RPG в тёмном фэнтези: боссы, деревня из пепла, кланы и 4 финала. Бесплатно, прямо в Telegram.
```
(99 символов)

### 3. Аватар — `/setuserpic`
Отправьте `userpic_640x640.png` **как фото** (не файлом).

### 4. Картинка описания — `/setdescriptionpic`
Отправьте `description_640x360.png` как фото.

### 5. Команды — `/setcommands`
Вставьте одним сообщением (все они реально обрабатываются в `server/src/routes/bot.js`):

```
start - Начать и открыть игру
play - Кнопка «Играть»
invite - Ссылка для друзей (подарок обоим)
notify - Включить напоминания
notify_off - Выключить напоминания
paysupport - Помощь с покупками
privacy - Политика конфиденциальности
terms - Пользовательское соглашение
```
(`/stop` тоже выключает напоминания, но в меню его не показываем.)

### 6. Кнопка меню — `/setmenubutton`
Выберите бота → пришлите URL `https://emberveil-dwp.pages.dev/emberveil/` → название кнопки: `Играть`.
(Либо в /mybots → бот → Bot Settings → Menu Button.)

### 7. Mini App — `/myapps` (или /mybots → бот → Bot Settings → Configure Mini App)
Приложение с коротким именем `play` (ссылка `t.me/emberveil_game_bot/play`) уже создано, проверьте:
- **Edit Web App URL**: `https://emberveil-dwp.pages.dev/emberveil/`
- **Edit Title**: `Эмбервейл`
- **Edit Description** (короткое описание в карточке приложения):
  ```
  Экшен-RPG в тёмном фэнтези: сражайся с боссами, отстрой деревню из пепла и выбери один из 4 финалов. Бесплатно.
  ```
- **Edit Photo**: `miniapp_cover_640x360.png`
- **Edit GIF** (по желанию): ролик боя 640×360, до 10 с.
- **Main Mini App** (Bot Settings → Configure Mini App → Enable): включите — у бота появится кнопка «Открыть» в профиле и в поиске, и ссылка `t.me/emberveil_game_bot?startapp`.

### 8. Платежи (Stars) и поддержка
- Telegram требует команду `/paysupport` для ботов с платежами — она есть. Ответы на обращения пока ручные: следите за чатом бота.
- В /mybots → Payments провайдер для Stars **не нужен** (валюта XTR).

### 9. Юридические ссылки
- `/privacy` и `/terms` бот отвечает ссылками на `…/legal/privacy.html` и `…/legal/terms.html` (папка `legal/` рядом с `WEBAPP_URL`; другой адрес — переменная `LEGAL_BASE_URL` в `server/wrangler.toml`).
- В игре: «Настройки» → «Об игре» → «Конфиденциальность» / «Соглашение»; там же «Удалить аккаунт и данные».
- **Перед запуском заполните заглушки** в `apps/legal/privacy.html` и `apps/legal/terms.html`:
  `[ИМЯ / ИП / ОРГАНИЗАЦИЯ]`, `[ИНН / ОГРН — если есть]`, `[EMAIL ДЛЯ СВЯЗИ]`, `[ДАТА]`, `[СТРАНА / ЗАКОН …]`, `[СТРАНА / ПРИМЕНИМОЕ ПРАВО]`, `[ПОРЯДОК / СУД …]` — и покажите тексты юристу (это черновики).
