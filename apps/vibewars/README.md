# ⚔️ VIBE WARS — стратегия + аркада + RPG

**Запуск:** открыть `apps/vibewars/index.html` (лучше в мобильном режиме). Управление: палец/WASD — бег, Пробел — навык, Shift — рывок.

## Сюжет
Город накрыл **Кринж**: люди превращаются в NPC — говорят шаблонами, ходят строем, ставят лайки не глядя. Кот Сигма 🐈‍⬛ находит последнего человека с аурой — тебя. Освободи 9 районов и победи Короля Кринжа в его Башне.

## Три жанра — один цикл
```
 СТРАТЕГИЯ (карта)          АРКАДА + TOWER DEFENSE (бой)        RPG (прогресс)
 выбрать район / оборону →  бегаешь героем, строишь башни,  →  лут, золото, кристаллы
 доход районов, угрозы  ←   перки на каждом уровне          ←  классы, шмот, таланты
```

### 🗺️ Стратегия — карта города
- 10 районов на графе: захватывать можно только соседние со своими. Каждый бой — 1 ход (день).
- Районы дают 💰 доход каждый ход.
- **Контратаки Кринжа:** каждый ход растёт угроза ⚠️ на одном из пограничных районов (с 9-го дня — на двух). На 3/3 район атакован: не отобьёшь его в следующий ход — потеряешь. Постоянный выбор: наступать или держать оборону.
- Районы открывают новые башни: Парк → Хил-станция, ТЦ → Мем-пушка, Технопарк → Глушилка.

### 🕹️ Аркада + Tower Defense — бой
- В центре **Вайб-ядро**. Враги идут волнами со всех сторон. Ядро уничтожено — поражение.
- Герой управляется джойстиком, атакует сам, есть **навык класса** и **рывок** с неуязвимостью. Погиб — возрождаешься через 6 сек, пока башни держат ядро.
- **Фаза стройки** между волнами: 14 площадок, 5 типов башен × 3 уровня, продажа. Энергия ⚡ — с убитых врагов. «▶ Волна» раньше таймера даёт бонус ⚡.
- Враги: 🙂 NPC, 😤 Хейтер (быстрый), 🧌 Тролль (танк), 🤖 Бот-ферма (при смерти выпускает ботов), 🥱 Душнила (стреляет и замедляет). В каждом районе свой босс (📏 Завуч Кринжа, 🦢 Гусь-Абьюзер, 🛒 Тележка Хаоса, 🎫 Контролёр Судьбы, 🖨️ Принтер Зла, 🕊️ Голубь-Мутант, 📣 Фанат-Душнила, 🦀 Краб-Токсик, 👑 Король Кринжа) — призывает свиту и стреляет кольцами.

### ⚔️ RPG — прокачка
- **3 класса** с разным стилем игры:
  - 🎥 Стример — дальний бой, навык «Донат-дождь»
  - 🛹 Скейтер — ближний бой по кругу, навык «Кикфлип» (рывок сквозь толпу)
  - 🎧 Диджей — пульс по площади, навык «Дроп баса» (ударная волна с отбросом)
- **15 перков** за уровни внутри боя (рогалик): фан-орбиты, цепная молния, вампиризм, мощь класса, ремонт ядра, прораб для башен и др.
- **Лут:** 3 слота (оружие / шмот / артефакт), 4 редкости, 10 типов характеристик, сравнение с надетым, продажа за 💰 и разбор на 💎. Сундуки за золото.
- **7 талантов** за кристаллы — навсегда.
- **NG+:** после победы над Королём начинается новый город — враги сильнее, лут лучше, прогресс героя сохраняется.

## Баланс (проверен симуляцией)
Бот с простой стратегией проводил по полному бою на каждый район:
- Базовый герой без шмота проходит районы 1–3★, на 4★ начинает проигрывать.
- С эпическим шмотом и талантами 3/5 проходится всё до Набережной (5★).
- Башня Кринжа проходится только хорошо прокачанным героем: таланты 5/5 и легендарный шмот. Это проверено для всех трёх классов.
