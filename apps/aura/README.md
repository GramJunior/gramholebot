# 🔮 AURA — фарми ауру каждый день

> Telegram Mini App / PWA для аудитории 13–24. Ежедневный ритуал: узнать цвет своей ауры, забрать стрик, выбить ауралинга и подняться в лиге.

**Запуск:** открыть `apps/aura/index.html` в браузере (лучше в мобильном режиме DevTools). Без сборки, без зависимостей, весь прогресс в `localStorage`.

---

## 1. Почему именно это (тренды)

| Тренд | Что берём |
|---|---|
| Мем «аура» / «aura farming» (+1000 aura, −1000 aura) — один из главных сленговых мемов Gen Alpha / Gen Z 2024–2026 | Вся метафора приложения: аура = валюта и статус. Титулы NPC → Main Character → Сигма → Абсолют |
| Tap-to-earn (Notcoin, Hamster) **остыл** — голое тапанье больше не держит | Тап — только вход. Удержание держат дейли-ритуалы, коллекция, лиги и мини-игры на скилл |
| Daily-ритуалы: гороскопы, «вайб-чеки», Wordle-подобные разовые события | Вайб-чек дня: цвет ауры, предсказание, вайб-скор, совместимость — новый каждый день, генерируется детерминированно |
| Blind box / коллекционки (Labubu и т.п.), гача | Аура-дропы: 24 оригинальных «ауралинга», 5 редкостей, гарант легенды, сеты |

| Лиги по неделям (Duolingo) | 5 лиг, 30 участников, топ-5 вверх, 5 последних вниз |

| Опросы «что лучше» / мнения | Мини-игра «Вайб или кринж» с процентами «как ответили другие» |
| Telegram Mini Apps: 500M+ взаимодействий в день, оплата в Stars | Нативная интеграция с Telegram WebApp SDK, haptics, инвайты через `startapp` |

## 2. Core loop

```
 Открыл приложение
   → оффлайн-доход «пока тебя не было» (до 3 ч)  ← повод зайти
   → Дейли: вайб-чек + стрик + 4 квеста          ← ритуал, 1–2 мин
   → Бесплатный дроп ауралинга                   ← дофамин
   → Тапы / мини-игры → аура                     ← core-геймплей
   → Прокачка (тап, энергия, реген, пассив, крит) ← прогрессия
   → Лига недели / приглашение друга / шер       ← соц. петля
   → Энергия кончилась → вернусь через час      ← сессии в течение дня
```

## 3. Что уже готово в v1.0

**Фарм**
- Орб-кликер: мультитач, «флоу»-комбо до ×2, криты ×10, частицы, звук, вибрация (Telegram HapticFeedback).
- Энергия + регенерация, 3 бесплатных «полных бака» в день, дальше — за рекламу.
- «Аура-шторм» — ×3 на 20 сек за рекламу.
- 5 улучшений с экспоненциальной стоимостью и капом уровней.
- Пассивный доход «Фан-клуб» + оффлайн-доход до 3 ч.
- 9 титулов от NPC до Абсолюта (прогресс-бар до следующего).

**Дейли**
- Вайб-чек: 12 цветов ауры (включая редкую «Радужную» 6%), 32 предсказания, вайб-скор, счастливое число, знак совместимости. Цвет дня **перекрашивает всё приложение**.
- Стрик 7 дней с растущими наградами, на 7-й день — дроп. Заморозки стрика.
- 4 случайных квеста в день из пула 10 (детерминированно по id игрока + дата).
- Aura Pass (сезон 1): 30 уровней, бесплатный трек работает, премиум-трек — заглушка под Telegram Stars.
- Бонус за рекламу (лимит 10/день).

**Мини-игры**
- **Aura Rush** — аркада на canvas: лови ауру, уворачивайся от 💀/🤡, бонусы 🧲 магнит / 🛡️ щит / ⭐ ×2, рост скорости. «Усталость» после 5 игр (×0.5), ×2 к награде за рекламу.
- **Вайб или кринж** — 8 тем дня из 55, проценты «как ответили другие», персона-результат.
- **Реакция** — 5 раундов, ранги от «Улиткина» до «Кибер-ниндзя».

**Дропы**
- 24 оригинальных ауралинга, 5 редкостей (58 / 27 / 11 / 3.5 / 0.5 %), гарант легенды каждые 40 дропов.
- Каждый новый ауралинг — постоянный % к фарму; 5 сетов с доп. бонусом; дубли → аура.
- Бесплатный дроп раз в день, далее за ауру (цена растёт с титулом) или за рекламу.

**Топ**
- Недельные лиги (Бронза → Сигма-лига), 29 соперников, зоны повышения/вылета, итоги недели с наградой.
  _Сейчас соперники — детерминированные боты (честная симуляция до появления бэкенда)._
- Реферальная ссылка `startapp=ref_<id>`, шер через Telegram, бонус новичку от друга.

**Прочее:** онбординг (4 слайда + ник из Telegram), профиль со статистикой, настройки звука/вибро, генерация карточки для сторис, автосохранение.

## 4. Экономика (кратко)

| Параметр | Формула |
|---|---|
| Сила тапа | `1 + lvl` |
| Энергия | `500 + 250·lvl`, реген `1 + lvl` / сек |
| Пассив/час | `180 · lvl · 1.22^lvl` |
| Крит | `2% + 2%·lvl`, макс. 40% |
| Цена улучшения | `base · k^lvl` (k = 1.55…1.9) |
| Масштаб наград | `max(400, тап·150 + пассив·0.6)` — награды растут вместе с игроком |
| Мультипликатор | `1 + Σ бонусов ауралингов + бонусы сетов` |

Все константы — в начале `<script>` (`CONFIG`, `UPS`, `RAR`, `DROP_COST` и т.д.).

## 5. Монетизация

1. **Rewarded-реклама** (основной доход на старте): полный бак, аура-шторм, ×2 за Rush, доп. дропы, бонус дня. Функция `showAd()` — точка подключения **Adsgram** / Telegram Ads / Monetag.
2. **Aura Pass Premium** за **Telegram Stars** (~199 ⭐ / сезон 30 дней): скины орба, рамки, эмодзи, бусты.
3. **Магазин за Stars**: заморозки стрика, наборы дропов, косметика. _Никакого pay-to-win в лигах._
4. **Партнёрские квесты**: «подпишись на канал / открой мини-апп партнёра» — стандартный доход TMA.

## 8. Структура кода

Один файл `index.html`: CSS-токены → разметка (5 вкладок + модалка + канвас игры) → JS-блоки: `CONTENT` (весь контент), `STATE`, `ECONOMY`, `DAILY`, `FX`, рендер вкладок, мини-игры, `boot()`.
