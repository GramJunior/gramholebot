# gramholebot

| Проект | Описание | Запуск |
|---|---|---|
| 🕳️ **Gram Hole 3D** | Существующая 3D-игра (Telegram Mini App) | `index.html` |
| 🔮 **AURA** | Ежедневное приложение для молодёжи: фарм ауры, вайб-чек дня, стрики, дропы-коллекционки, 3 мини-игры, недельные лиги, Aura Pass. [Концепция, экономика, монетизация, роудмап →](apps/aura/README.md) | `apps/aura/index.html` |
| ⚔️ **VIBE WARS** | Стратегия на карте города + аркадный tower defense + RPG (классы, перки, лут, таланты, боссы, NG+). [Подробнее →](apps/vibewars/README.md) | `apps/vibewars/index.html` |
| 🪐 **ORBITA** | One-tap аркада с челленджем дня (один уровень для всех) и шером результата. [Подробнее →](apps/orbit/README.md) | `apps/orbit/index.html` |

Лаунчер всех проектов: `apps/index.html`. Все проекты — один HTML-файл без сборки, прогресс хранится в `localStorage`, готовы к запуску как Telegram Mini App (WebApp SDK, haptics, `startapp`-рефералы).
